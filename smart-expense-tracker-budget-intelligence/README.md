# Smart Expense Tracker & Budget Intelligence System

A beginner-friendly Data Science project for tracking expenses, analyzing spending patterns, managing monthly budgets, detecting unusual expenses, and generating simple budget intelligence.

## Tech Stack
- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit

## Features
- Add and view expenses
- Category-wise spending analysis
- Monthly spending trends
- Budget vs actual comparison
- Overspending detection
- Average daily spending
- Simple next-month expense forecast
- Interactive dashboard

## Run
```bash
pip install -r requirements.txt
streamlit run dashboard/app.py
```

The dashboard creates `data/expenses.csv` automatically if it does not exist.
